Overview

RJL-zap Slack Bot

RJL-zap replaces the firm's Zapier automations. It lives in Slack and listens for @-mentions. When you trigger a command, it posts checklists, sends timed follow-up messages, and escalates to supervisors if something isn't confirmed — so nothing falls through the cracks.

Always start with @RJL-zap. The bot only responds when you explicitly mention it. Just typing a phrase on its own won't trigger anything.
Need help in Slack? Type @RJL-zap help (or faq, commands, what can you do) in any channel — the bot will reply in the thread with a link to this page.
How it works
1
Type a command
In any case channel, mention @RJL-zap followed by a command phrase like answer filed or mediation checklist.
2
Bot responds in a thread
RJL-zap immediately posts a checklist or task in the thread of your message and tags whoever you mentioned.
3
Mark items done
React ✅ on each item as you complete it, or reply done in the thread. The bot stops reminding automatically.
First time in a channel? Slack will show a popup asking to add RJL-zap — click Add to channel and it will respond normally. You only need to do this once per channel.

Calendar Checklists

Use these when a key case event happens and deadlines need to go on the calendar. The bot posts a checklist in the thread and nudges every 24 hours until every item is ✅.

Recent Contact

Logs any client interaction to the Recent Contact Google Sheet — emails, texts, calls, voicemails, letters, mail, faxes, and in-person visits. Use this any time you've reached out to or heard from a client.

Format
@RJL-zap recent contact <type> - <details>
Email
@RJL-zap recent contact email - Re: discovery responses
Phone Call
@RJL-zap recent contact call - discussed depo prep, 15 min
In-Person Visit
@RJL-zap recent contact visit - client came in to sign release
Voicemail
@RJL-zap recent contact voicemail - left vm re: settlement offer
Text Message
@RJL-zap recent contact text - confirmed appt tomorrow 10am
Letter / Mail / Fax
@RJL-zap recent contact mail - sent signed release
Accepted types: email, text, call, voicemail, letter, mail, fax, visit, other
Synonyms also work — e.g. called, texted, spoke with, met with, dropped by, left vm.
Row schema:
  • Timestamp (UTC)
  • Slack channel name & ID
  • Case number & case name (parsed from channel name, e.g. smith-john-12345)
  • Type (canonical: email / text / call / voicemail / letter / mail / fax / visit / other)
  • Details (the text after the type)
  • Full original Slack message
  • Logged by (the person who typed the command)
Setup required: An admin must paste the service account JSON into the GOOGLE_SERVICE_ACCOUNT_JSON env var on Railway, set the spreadsheet ID in admin settings, and share the sheet with the service account email.

Thread replies

Some commands require a reply inside the thread to mark something complete or close a workflow early.

Mark intro/setup complete
done
Stops the escalation timer for attorney intro, paralegal intro, and case setup.
Confirm check pickup scheduled
scheduled
Stops the escalation timer for the check pickup workflow.
Close any workflow early
@RJL-zap COMPLETE
Immediately closes the checklist and stops all reminders, even if not every ✅ is checked.
Important: Replies must go inside the thread started by the bot — not in the main channel. Click Reply under the bot's message to open it.
FAQ
What if I type the command and nothing happens?
Make sure you @-mentioned @RJL-zap — just typing the phrase without the @-mention won't trigger anything. If it's the first time in this channel, Slack may have shown a prompt to add the bot — look for a system message and click Add to channel, then try again. If it still doesn't respond, contact your admin.
Can I trigger a workflow more than once in the same channel?
Yes — each individual @-mention message starts its own workflow thread. Post a new @RJL-zap message and a new workflow begins. Previous ones stay open until completed.
What does "reply done in the thread" mean exactly?
Click Reply under the bot's message to open the thread, then type the word done and send. The bot checks for this keyword and will stop the escalation timer. For check pickup, type scheduled instead.
How do I close a checklist if everything is already done?
Reply @RJL-zap COMPLETE in the thread to close it immediately. Or just react ✅ to every checklist item — the bot closes it automatically when all are checked.
What happens if something isn't confirmed in time?
For workflows with escalation (attorney intro, paralegal intro, case setup, check pickup), the bot posts a follow-up in the thread and tags the supervisors or backup contacts configured by your admin. Both the original person tagged and the supervisors will see the escalation message.
What if I accidentally triggered a workflow?
Reply @RJL-zap COMPLETE in the thread right away. That closes it immediately and cancels all scheduled reminders.
How does Recent Contact work?
Type @RJL-zap recent contact <type> - <details> in any case channel. The bot parses the type, parses the case number from the channel name (expects case-name-12345 format), and appends a row to the Google Sheet configured in admin settings. The "- " separator is optional — `recent contact call discussed depo prep` works too. If you type recent contact without a recognized type, the bot replies with usage instructions in the thread.
Who gets the reminder messages?
Checklist reminders (24-hour nudges on open calendar items) go to the @legalassistants group. Escalation messages for intro and setup workflows tag the backup contacts configured by your admin. The person you originally tagged in the trigger message is always included.
Admin Settings
Server Environment Variables

These must be set in Railway → Variables (or your hosting dashboard). They are not editable on this page.

SLACK_BOT_TOKEN required Bot's Slack credentials — starts with xoxb-
SLACK_APP_TOKEN required Socket Mode connection token — starts with xapp-
WEB_PASSWORD Password to protect this admin page (recommended)
BOT_DB_PATH Path to database file — set to /data/bot.db if using a Railway volume
GOOGLE_SERVICE_ACCOUNT_JSON Full JSON key for the Google service account that writes to the communication log sheet. Paste the entire JSON object as a single env var value.
FAQ_URL URL the bot replies with when someone types @RJL-zap help. Default: this page.
