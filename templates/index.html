Quick Reference

How do I trigger the bot?
@-mention @Jamie in any channel followed by a recognized phrase (see Workflows below). The first time you mention Jamie in a channel, Slack will prompt you to invite it — click Add to channel.
How do I mark a task complete?
React ✅ on individual checklist items as you finish them. To close an entire workflow at once, reply @Jamie COMPLETE in the thread.
Who gets reminded?
Reminders always post in the original thread so everyone following it sees them. Some workflows also tag specific escalation contacts (configured in Settings below) if no one responds.
How often does the bot send reminders?
Checklist workflows (answer filed, discovery, scheduling) remind every 24 hours until all items are checked off. Mediation and disbursement follow a fixed schedule. Intro workflows escalate once if no done reply is received.
Can I run a workflow again in the same channel?
Each original trigger message can only start one workflow. To start a new one, post a new @Jamie mention in the channel.
How do I find a Slack user ID?
Click any person's name or avatar in Slack → click the ⋮ (three dots) → Copy member ID. It looks like U026P9FUKHC. Paste it into the Settings fields below.
