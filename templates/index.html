Getting Started
What is RJL-flow?

RJL-flow is a Slack bot that automatically sends checklists, reminders, and follow-ups so nothing falls through the cracks on a case. You trigger it by typing its name in Slack. It handles the follow-up from there.

① Type a command
In any case channel, mention @RJL-flow followed by a command phrase.
② Bot responds in a thread
RJL-flow posts a checklist or task directly in the thread of your message.
③ Mark items done
React ✅ on each item, or reply done in the thread. The bot tracks it and stops reminding.
First time in a channel?

When you mention @RJL-flow in a channel it hasn't been added to yet, Slack will show a popup asking "Add RJL-flow to this channel?" — click Add to channel and the bot will respond normally. You only need to do this once per channel.

Calendar Checklists

Use these when a key case event happens and you need to make sure all the deadlines get on the calendar. The bot posts a checklist and reminds every 24 hours until every item is checked off.

Answer Filed
@RJL-flow answer filed
  • Calendar Initial Disclosures
  • Calendar Chapter 18 deadline
  • Calendar controverting affidavit
  • Update case management calendar
Discovery Requests Received
@RJL-flow discovery requests received
  • Calendar 30-day response deadline
  • Calendar draft review deadline
  • Assign drafter for responses
Scheduling Order Agreed
@RJL-flow scheduling order agreed
  • Calendar discovery cutoff
  • Calendar expert disclosures
  • Calendar dispositive motions
  • Calendar trial date
Calendar Statute of Limitations
@RJL-flow calendar sol
  • Calendar the SOL deadline with exact date
  • Set 30-day advance reminder
  • Set 7-day advance reminder
To mark items done: React ✅ on each thread item as you calendar it. Once every item has a ✅, the bot closes the checklist automatically and stops reminding.

30-Day Disbursement Timer ⚠ Restricted

Starts the full 30-day disbursement workflow. Only authorized users can run this command (see Admin Settings below). The bot reads the channel topic to find the responsible team members.

Type this
@RJL-flow start disbursement
Bot immediately posts: Full 5-phase disbursement checklist (Settlement → Medical Bills → Release → Funding → Disbursement)
30 min Disbursement overview
3 hours Cancel orders & gather invoices
22 hours Medical bills check-in
24 hours Settlement confirmation
Day 3 Reductions update
Day 7 Release signatures
Day 14 Funding & check issuance
Day 17 Deposit confirmation
Day 21 Expense reconciliation
Day 30 Final disbursement deadline
To close this workflow early, reply @RJL-flow COMPLETE in the thread.

Frequently Asked Questions
What if I type the command and nothing happens?
First, make sure you @-mentioned @RJL-flow (not just typed the phrase). If it's the first time the bot is being used in this channel, Slack may have shown a prompt to add the bot — look for a system message and click Add to channel, then try again. If the bot still doesn't respond, let your admin know.
Can I trigger a workflow more than once in the same channel?
Yes — but each individual message can only start one workflow. Just post a new @RJL-flow message and a new workflow starts. The old one stays open until you complete it.
What does "reply done in the thread" mean?
Click Reply under the bot's message (not the original trigger message) to open the thread, then type the word done and hit send. The bot will see it and stop the escalation timer. For the check pickup workflow, type scheduled instead of done.
How do I close a checklist early if everything is done?
Reply @RJL-flow COMPLETE in the thread. This immediately closes the workflow and stops all reminders, even if not every ✅ has been added yet. Alternatively, just react ✅ to every item — the bot closes it automatically when all are checked.
What happens after 48 hours if something isn't done?
For workflows with escalation (attorney intro, paralegal intro, case setup, check pickup), the bot posts a follow-up in the thread and tags the supervisors or backup contacts configured by your admin. You'll see an ⚠️ warning message and the original person plus supervisors will be tagged.
What if I accidentally trigger a workflow?
Reply @RJL-flow COMPLETE in the thread right away — that closes it immediately and stops any scheduled reminders.
Who gets the reminders and escalation messages?
Checklist reminders (24-hour nudges) go to the @legalassistants group. Escalation messages for intro and setup workflows tag the people configured by your admin in the settings below. The original person you tagged in the trigger message is always tagged in every message.
