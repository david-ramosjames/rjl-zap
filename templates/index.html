Overview

RJL-zap Slack Bot

RJL-zap replaces the firm's Zapier automations. It lives in Slack and listens for @-mentions. When you trigger a command, it posts checklists, sends timed follow-up messages, and escalates to supervisors if something isn't confirmed — so nothing falls through the cracks.

Always start with @RJL-zap. The bot only responds when you explicitly mention it. Just typing a phrase on its own won't trigger anything.
Need help in Slack? Type @RJL-zap help (or faq, commands, what can you do) in any channel — the bot will reply in the thread with a link to this page.
Ad-hoc commands

These don't fit the channel-lifecycle flow — they're commands you @-mention any time a specific case event happens or when you've contacted a client. Use them as often as you need.

Use these when a key case event happens and deadlines need to go on the calendar. The bot posts a checklist in the thread and nudges every 24 hours until every item is ✅.

Completing items: React ✅ on each thread item as you calendar it. Once every item has a ✅, the bot closes the checklist and stops reminding automatically.

Recent Contact Manual

Logs any client interaction to the Recent Contact Google Sheet — emails, texts, calls, voicemails, letters, mail, faxes, and in-person visits. Use this any time you've reached out to or heard from a client.

Format (either phrase works)
@RJL-zap recent contact <type> - <details>
@RJL-zap client contact <type> - <details>
Email
@RJL-zap recent contact email - Re: discovery responses
WhatsApp
@RJL-zap client contact via WhatsApp - sent client a case update
Other Messaging (Messenger, portal, etc.)
@RJL-zap recent contact message - replied on client portal
In-Person Visit
@RJL-zap recent contact visit - client came in to sign release
Letter / Mail
@RJL-zap recent contact mail - sent signed release
Fax
@RJL-zap recent contact fax - records request faxed to provider
Phone calls, texts, and voicemails are tracked automatically by the firm's phone system — no need to log them via recent contact. The bot will gently redirect if you do. Use this command for the contact types the phone system doesn't capture.
Accepted types: email, whatsapp, message, letter, mail, fax, visit, other
Synonyms also work — message covers Facebook Messenger, Instagram, Signal, Telegram, and client-portal messages; you can also write via WhatsApp, mailed, met with, dropped by, faxed.
Row schema:
  • Timestamp (Central Time, formatted so Google Sheets parses it as a real datetime — works with =DAYS(), sorting, etc.)
  • Slack channel name & ID
  • Case number & case name (parsed from channel name, e.g. smith-john-12345)
  • Type (canonical: email / text / call / voicemail / letter / mail / fax / visit / other)
  • Details (the text after the type)
  • Full original Slack message
  • Logged by (the person who typed the command)
Setup required: An admin must paste the service account JSON into the GOOGLE_SERVICE_ACCOUNT_JSON env var on Railway, set the spreadsheet ID in admin settings, and share the sheet with the service account email.
How it works
1
Type a command
In any case channel, mention @RJL-zap followed by a command phrase like answer filed or mediation checklist.
2
Bot responds in a thread
RJL-zap immediately posts a checklist or task in the thread of your message and tags whoever you mentioned.
3
Mark items done
React ✅ on each item as you complete it, or reply done in the thread. The bot stops reminding automatically.
RJL-zap is already in every public channel. No need to invite or add it — the bot auto-joins every public channel on startup and immediately joins any new channel as it's created. Just @-mention it and it responds.
Private channels are the exception. Slack does not allow bots to self-join private channels. In a private channel, type /invite @RJL-zap once to add it.
Automatic

These workflows fire on their own as a case progresses through Slack — new channel created, channel description set, certain phrases posted. Each can also be triggered manually via @-mention; the manual command for every one is shown on its card below.

How automatic triggers work Overview

Three event sources drive every automatic workflow in the firm:

Channel creation
New public channel → bot joins, then runs a timed sequence: +180 sec, +15 min (Case Setup + SOL), +1 hr, +48 hrs.
Channel description
When the description is set to Attorney @X | Paralegal @Y, the bot fires the intros for those specific people.
Phrase in any message
Phrases like "mediation checklist" or "law firm can be paid" trigger workflows directly from the chat.
On creation Bot auto-joins the new public channel.
+180 sec New Case Assignment notifies the case assignee.
+15 min Case Setup checklist & Calendar SOL checklist post.
+1 hr Client Intake request posts to the assigned collector.
+48 hrs Document Verification checklist posts.
Description set Attorney Intro + Paralegal Intro fire for the named people.
Phrase posted Mediation Checklist (anyone) or Check Pickup (configured users only).
Case-number gate. Every channel-creation and description-set auto-trigger above only fires in channels whose name ends in a case number — e.g. lacayoarauzjose-1559 or smith-john-12345. Channels without a trailing -<number> (e.g. general, team-updates) still get the bot, but stay silent — use manual @-mention commands if you need a workflow there. Phrase triggers (Mediation, Disbursement, Check Pickup, Review Request) are not gated and work everywhere.
Auto-tagged participants: When Case Setup and Doc Verification fire automatically there's no @-mention to pull from. Set Case Setup / Doc Verification — Auto-Tagged Participants in admin settings so the right people get pinged.
Private channels: Bots can't self-join private channels, so the channel-creation sequence only runs in public channels. For private channels, type /invite @RJL-zap, then trigger workflows manually with the commands on each card.

Weekly Status Report Auto

Posts a digest of everything still open, once a week. Default: Friday at 5:30 PM Central to the channel set in admin settings (e.g. daily-pulse). Lists every workflow started in the last 7 days that nobody has marked done — grouped by whether it has already been escalated.

Each line shows:
  • The case channel (clickable)
  • Which action is still open — Case Setup, Client Intake, Document Verification, intros, Check Pickup, calendar checklists…
  • How long it's been open
  • What reply closes it (done, confirmed, scheduled) — or how many checklist items are still unchecked
🔴 Escalated The reminder already fired and still no reply — these need attention first.
🟡 Open Still within the normal window; no escalation sent yet.
Configurable in admin settings: Weekly Status Report — Channel (leave empty to turn the report off), Day (e.g. friday), Time (e.g. 17:30 or 5:30 PM, Central), and Lookback in days. The bot must be a member of the target channel.
Misses are handled. If the bot is restarting at the scheduled minute it posts on the next check instead (checks run every ~4 minutes). If it was offline more than 48 hours past the slot, that week is skipped rather than posting a stale report — and it never posts a backlog of catch-up reports at once.
Client Contact Status Alerts Auto

Once-a-day sweep of the Client Contact Status Google Sheet, weekdays during business hours. For every case whose Days Since Contact (column G) has reached a threshold, the bot posts to the matching case channel and tags users from the channel topic.

25 days :hourglass_flowing_sand: Heads up — early nudge to reach out before the 30-day mark.
30 days :warning: Warning — first formal reminder. Tags topic users with a prompt to log the next outreach via @RJL-zap recent contact.
45 days :rotating_light: Reminder — escalation message that the lapse is still open.
60 days :no_entry: Urgent — case needs immediate attention; blockers should be documented in-thread.
75 days :bangbang: Critical — escalate to the supervising attorney, document why the case has lapsed.
Highest threshold wins. Only one alert fires per case per day — whichever threshold the case has crossed highest. All lower crossed thresholds are silently back-recorded so they can't back-fire later. A case that jumps from a fresh contact straight to 70 days (e.g. data gap) gets the 60-day alert, not 25/30/45 in sequence.
Business hours only: the sweep only fires Mon-Fri, 9 AM – 5 PM Central. A case that crosses the threshold over a weekend or overnight is alerted on the next business-hours tick. The 24-hour gate also means at most one alert per case per day.
Topic-only tagging: the bot reads only the channel's topic for @-mentions — never the description. So if your topic says Attorney @Kody | Paralegal @Adrian and the description names someone different, only @Kody and @Adrian get pinged.
How channels are matched: the bot looks up the case channel by parsing the trailing -<case-number> from each public channel name. Case 232 in the sheet matches a channel named e.g. charliebrown-232. Cases without a matching channel are silently skipped (logged for diagnostics).
Sheet is the source of truth. The bot only alerts on cases that are currently in the sheet. If a case number is removed from column A (case closed, settled, withdrawn), no further reminders fire — there's nothing to opt out of. The next sweep just won't see the case. The log line N case(s) previously alerted on are no longer in the sheet shows how many cases dropped off since the bot started.
Re-arms after a logged contact. Each alert is keyed on the case + threshold + Last Interaction date. Once someone logs a new contact and the sheet's Last Interaction column updates, the case can fire the 30-day warning again the next time it lapses past 30 days.
Setup: requires the GOOGLE_SERVICE_ACCOUNT_JSON env var (same one Recent Contact uses) and the spreadsheet ID set under Client Contact Status — Google Sheet ID. Share the sheet with the service account email. Read-only — the bot never writes to this tracker.

FAQ
What if I type the command and nothing happens?
Make sure you @-mentioned @RJL-zap — just typing the phrase without the @-mention won't trigger anything. The bot auto-joins every public channel, so it should respond anywhere. If you're in a private channel, type /invite @RJL-zap once to add it (Slack doesn't allow bots to self-join private channels). If it still doesn't respond, contact your admin.
Can I trigger a workflow more than once in the same channel?
Yes — each individual @-mention message starts its own workflow thread. Post a new @RJL-zap message and a new workflow begins. Previous ones stay open until completed.
What does "reply done in the thread" mean exactly?
Click Reply under the bot's message to open the thread, then type the word done and send. The bot checks for this keyword and will stop the escalation timer. For check pickup, type scheduled instead.
How do I close a checklist if everything is already done?
Reply @RJL-zap COMPLETE in the thread to close it immediately. Or just react ✅ to every checklist item — the bot closes it automatically when all are checked.
What happens if something isn't confirmed in time?
For workflows with escalation (attorney intro, paralegal intro, case setup, check pickup), the bot posts a follow-up in the thread and tags the supervisors or backup contacts configured by your admin. Both the original person tagged and the supervisors will see the escalation message.
What if I accidentally triggered a workflow?
Reply @RJL-zap COMPLETE in the thread right away. That closes it immediately and cancels all scheduled reminders.
What happens automatically when a new case channel is created?
The bot watches for new public channels and runs this sequence with no @-mention required:
  1. Immediately: Bot joins the channel.
  2. ~180 seconds after creation: New Case Assignment fires — pings the configured assignee.
  3. +15 minutes: Case Setup checklist posts — confirm contract, intake, CTA saved — and the Calendar Statute of Limitations checklist posts so the SOL is calendared during the assignment phase.
  4. +1 hour: Client Intake request posts — assigned collector gathers client details.
  5. +48 hours: Legal Case Document Verification posts — verify everything is properly filed once the case has had a couple days to gather documents.
  6. When the channel description is set: If it includes Attorney @X | Paralegal @Y, Attorney Intro and Paralegal Intro fire for those specific people. Only fires the first time — later edits to the description do not re-fire.
The same workflows can also be triggered manually any time via @-mention — useful for private channels (where the bot needs to be /invite'd) or to re-fire the checklist later.
How does Recent Contact work?
Type @RJL-zap recent contact <type> - <details> in any case channel. The bot parses the type, parses the case number from the channel name (expects case-name-12345 format), and appends a row to the Google Sheet configured in admin settings. The "- " separator is optional — `recent contact call discussed depo prep` works too. If you type recent contact without a recognized type, the bot replies with usage instructions in the thread.
Who gets the reminder messages?
Checklist reminders (24-hour nudges on open calendar items) go to the @legalassistants group. Escalation messages for intro and setup workflows tag the backup contacts configured by your admin. The person you originally tagged in the trigger message is always included.
